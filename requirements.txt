# Python dependencies for the UnionLabs SDR platform.
#
#     pip install -r requirements.txt
#     ./run.sh selftest          # confirm it worked
#
# This covers everything that runs WITHOUT a radio — the ideal PHY, the LoRa PHY's sim
# backend, and every experiment. That is the whole platform for a newcomer.
#
# It does NOT install the C++ side (the USRP modem, UHD, the pyphy extension). For that:
#     deploy/initialization.sh --build
#
# PYTHON: 3.8 or newer. Note the prebuilt pyphy extension in drivers/usrp/bindings is
# compiled for ONE version+platform, so `--channel usrp` needs a build for your Python
# (drivers/usrp/bindings/build.sh). Nothing else here cares which version you use.
